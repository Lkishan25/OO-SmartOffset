Features — Modes & Hotkeys
5@100mm
Array Mode
5 offsets at 100mm spacing in one command. Any count, any unit.
4#400mm
Divide Mode
4 lines total within 400mm — 3 equal gaps of 133mm each. No calculator needed.
100g50mm
Gap Mode
Outer wall + 50mm cavity + inner wall. Three lines, one command.
Smart Hotkeys
